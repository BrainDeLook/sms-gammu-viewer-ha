# SMS Gammu Viewer Card — Справочник по настройке

> 🇬🇧 [English version](CARD.md)

Карточка для дашборда встроена прямо в интеграцию [SMS Gammu Viewer](https://github.com/BrainDeLook/sms-gammu-viewer-ha) — отдельная установка не нужна. Визуального редактора пока нет, поэтому карточка настраивается полностью через YAML.

## Добавление карточки

**Редактировать дашборд → Добавить карточку → Вручную**, затем вставь свой конфиг, либо добавь сразу в YAML дашборда.

## Все ключи конфигурации

| Ключ | Тип | По умолчанию | Описание |
|---|---|---|---|
| `type` | строка | — | Всегда `custom:sms-gammu-viewer-card`. Обязателен. |
| `title` | строка | `"SMS"` | Текст в заголовке карточки. |
| `max_items` | число | `5` | Максимальное количество диалогов для отображения. Диалоги сортируются по дате последнего сообщения (сначала новые); этот параметр ограничивает сколько показывать, независимо от общего числа диалогов. |
| `show_unread_only` | булево | `false` | При `true` показываются только диалоги хотя бы с одним непрочитанным сообщением. Прочитанные диалоги полностью отфильтровываются (не просто скрываются переключателем). |
| `panel_url` | строка | `"/sms-viewer"` | URL панели в сайдбаре, куда ведёт переход при клике на диалог или ссылку «Открыть все сообщения». Меняй только если ты как-то кастомизировал URL панели в интеграции — по умолчанию совпадает со значением интеграции «из коробки». |

## Полный пример — все ключи указаны явно

```yaml
type: custom:sms-gammu-viewer-card
title: Последние SMS
max_items: 8
show_unread_only: true
panel_url: /sms-viewer
```

## Минимальный пример — только значения по умолчанию

```yaml
type: custom:sms-gammu-viewer-card
```

Это эквивалентно:

```yaml
type: custom:sms-gammu-viewer-card
title: SMS
max_items: 5
show_unread_only: false
panel_url: /sms-viewer
```

## Готовые варианты конфигурации

**Компактный виджет только с непрочитанными, удобен для маленького уголка дашборда:**
```yaml
type: custom:sms-gammu-viewer-card
title: Непрочитанное
max_items: 3
show_unread_only: true
```

**Полный обзор последней активности:**
```yaml
type: custom:sms-gammu-viewer-card
title: Все сообщения
max_items: 15
show_unread_only: false
```

## Особенности поведения

- Карточка опрашивает API интеграции каждые 15 секунд пока видна на экране — счётчики непрочитанных и превью текста обновляются без ручного обновления страницы.
- Клик по любому диалогу или ссылке «Открыть все сообщения →» внизу открывает полную панель SMS Gammu Viewer в сайдбаре.
- Значок непрочитанных в заголовке карточки показывает **общее** количество непрочитанных по всем диалогам, а не только по отображаемым (то есть на него не влияет `max_items`).
- Требует установленную и настроенную интеграцию SMS Gammu Viewer — сама по себе карточка не функциональна.
